# 飞牛影视 Kodi 插件 (plugin.video.fnmedia)

访问 fnOS NAS 上的飞牛影视（Trim Media）媒体库：浏览电影、剧集（含蓝光原盘多版本）、其他视频，直接在 Kodi 中播放。

基于 [fntv-electron](https://github.com/QiaoKes/fntv-electron) 项目的 API 逆向分析开发。

## 功能

- ✅ 账号密码登录（Authx 签名认证，与官方 Web 客户端一致）
- ✅ 媒体库/目录浏览（item/list + episode/list）
- ✅ 蓝光原盘多版本支持（BDMV 多个 MPLS 版本 → 右键"选择版本播放"）
- ✅ 本地流媒体代理（自动注入 Authorization/Cookie 头，支持 Range 拖动）
- ✅ 网盘直链播放统一逻辑（115/天翼/夸克/阿里等）：换链声明 Kodi UA + 自洽
  探测，探测通过直接交给播放器直连 CDN；ISO/BDMV 支持 VFS 插件直链取流
- ✅ 外挂字幕自动下载并挂载
- ✅ 断点续播（服务端进度 → 自动从上次位置继续）
- ✅ 观看进度回传（多端进度同步）
- ✅ 标记已观看

## 安装

### 方式一：ZIP 安装
1. 使用打包好的 `plugin.video.fnmedia-0.1.1.zip`
2. Kodi → 设置 → 插件 → 从zip文件安装（需先开启"未知来源"）

> 插件零外部依赖（仅用 Python 标准库），安装不需要访问 Kodi 官方仓库，
> 无网络也能装。

### 方式二：直接复制
```
# macOS / Linux
cp -r plugin.video.fnmedia ~/.kodi/addons/
# Windows
xcopy /E /I plugin.video.fnmedia %APPDATA%\Kodi\addons\plugin.video.fnmedia
```
重启 Kodi。

## 配置

插件设置中填写：

| 设置 | 说明 |
|------|------|
| 服务器地址 | fnOS 的 IP 或域名，可带端口，如 `192.168.1.10` 或 `nas.example.com:5666`；也可填完整 `http://...` |
| 使用 HTTPS | NAS 启用 HTTPS 时开启 |
| 用户名/密码 | fnOS 登录账号（与 Web 端相同） |
| 验证服务器证书 | 自签名证书请保持关闭（默认关闭） |
| 优先使用云盘直链 | 媒体在夸克/115/阿里云盘时走直链（默认开，速度更快） |
| 媒体库根 GUID | 见下文"根 GUID 说明" |

## 使用

1. 配置好服务器与账号后打开插件
2. 进入"媒体库"浏览 → 文件夹逐级进入 → 电影/剧集点击播放
3. 蓝光原盘多版本：**右键 → 选择版本播放**（正片/加长版/导演剪辑版等）
4. 标记已观看：右键菜单

## 根 GUID 说明

插件默认尝试用空 parent_guid 获取顶级媒体库。**如果"媒体库"打开后为空或报错**：

1. 浏览器打开飞牛影视 Web 端，进入某个媒体库
2. 地址栏 URL 形如 `http://nas/v/library/fv_xxxxxxxx` 或 `http://nas/v/folder/xxxx`
3. 复制最后一段 GUID（含 `fv_` 前缀），填入插件设置的"媒体库根 GUID"

也可以用插件主菜单的"浏览指定 GUID / 链接"，直接粘贴 Web 端链接。

## 技术架构

```
Kodi ──播放──> 本地代理(127.0.0.1:22346) ──注入头──> NAS /v/api/v1/media/range/{media_guid}
   │                  │                                  或 云盘直链（带 Cookie/UA）
   │                  └──海报/图片──> /image?url=... ──同上
   └─网盘直链(探测通过)────────────────直连 CDN（必要时带 |User-Agent/Cookie 管道头）
service.py ──播放结束──> POST /v/api/v1/play/record（进度回传）
```

### 网盘直链统一逻辑（0.3.0）

网盘条目（115/天翼/夸克/阿里等）按同一套决策链取流，不再按"是否要求特定 UA"
判死链路：

1. **换链声明播放端完整 UA**：网盘直链与换链 UA 精确绑定。本地代理从真实
   请求（海报图片、视频流）捕获播放端实际发送的完整 UA 串并落盘（视频端
   UA 优先）——Kodi 原生 curl 与 vfs.stream.fast（`kodi::network::
   GetUserAgent()`）默认发送的正是它，换链时原样声明即可，直链天然匹配、
   无需注入；响应 header 回显的 UA/Cookie 以 Kodi 管道参数（`url|UA=..`）
   兜底附加。未捕获到采样前（安装后首次播放）自动走本地代理，首播必然
   可用并完成采样，之后自动切直链。
2. **自洽探测**：用与播放完全相同的请求头发 `Range: bytes=0-0`，仅接受 206
   ——探测头 = 播放头，探测 206 则播放必 206（杜绝 0.2.18 修复过的 206 假阳性）。
3. **有效期门控**：直链剩余有效期不足 `max(2×片长, 1h)` 时不直连（直连后链接
   中途过期无自愈手段），回退本地代理（代理有 401/403 失效重取）。
4. **ISO/BDMV 扩展名规则**：Kodi 靠 URL path 尾部扩展名识别光盘镜像（扩展名
   放在 `?` 参数里无效）。直链 path 自带 `.iso` 才裸直连；配置了"VFS 插件
   scheme"（高级设置）时经 VFS 取流，URL 形如
   `<scheme>://play/<文件名>.iso?d=<base64url 描述符>`，描述符为自包含 JSON：
   `u`=直链、`h`=请求头（UA/Cookie）、`x`=过期时间戳（base64url 无填充，解码端
   需补齐 `=`）。**VFS 插件需自行实现**：按描述符注入请求头、每链接并发 ≤2
   （115 风控）、精确 Range/Seek/Stat；未配置 scheme 时 ISO 走本地代理
   （`/stream/<guid>/<名>.iso` 的装饰段同样满足扩展名规则）。
5. **回退链**：直链解析/探测失败 → 本地代理（NAS 中转优先，网盘 strm 的
   NAS 400 负缓存后自动转"云链+头注入"转发）。

- 认证：`Authx: nonce=&timestamp=&sign=MD5(api_key_url_nonce_ts_md5(body)_secret)`，与 Web 端一致，签名已通过 TS/Python 双端比对测试
- 代理：Python `ThreadingHTTPServer`，每请求一线程，HTTP/1.0 短连接，Range/If-Range 透传

## 已知限制

- 顶级媒体库的发现 API 未知（Web 端未公开），首次使用可能需手动填根 GUID
- 夸克网盘直链未实现 10MB 分块对齐（Go 版优化），大文件高码率可能偶发卡顿；如遇问题可关闭"云盘直链"走 NAS 转发
- FN ID 远程登录（5ddd.com 中转）暂不支持，仅支持局域网/直连地址
- 剧集自动连播依赖 Kodi 播放列表行为，暂未实现整季播放列表
